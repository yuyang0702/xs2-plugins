---
name: longrun
description: Opt-in long-form copy validation, usage observation, anchored audits and resumable real-model acceptance runs.
type: python
---

`longrun status` reports accepted new prose, audit coverage, recoveries and actual
provider usage. Unknown prices/outcomes stay visible, never assumed free.
The plugin's `runtime/longrun/main.py run` launches the native host adapter on an
initialized copy, with explicit model routes and external-run authorization.
The Script Library itself stays independent and never imports the host adapter.
The copy's own style, narrative permissions and world rules govern all agents.
