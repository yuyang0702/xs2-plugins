# Compact short-story preparation

Plugin-owned, file-only preparation for explicitly selected standalone shorts.

- `world --input cache/short/world.json`: validate a single world response and produce the six original archive JSON categories plus `meta/world_foundation.md`. Irrelevant categories remain empty.
- `characters --input cache/short/characters.json`: validate the full cast, individual relationships and voices before publishing profiles, voice Markdown, skeleton and voice cache.
- `context --chapter 0001`: retain complete canonical foundations, current facts, approved writing and voice adaptations. Produce the original single-writer/post-hoc input files without inventing new events. No novel body is authored here.

Existing different outputs are preserved and cause a clear stop. Invalid/oversize input is rejected before publication. The first-chapter shortcut refuses existing prose and later chapters. Other workflows retain the standard path; this helper never rewrites model configuration or library sources.
