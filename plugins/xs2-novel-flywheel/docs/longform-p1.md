# 长篇 P1：远距检索、身份与认知、修订影响

写作、顾问、审稿和修订共用 story_support 上下文。P1 在 P0 可信快照之上增加可重建的 `archive/memory-index.sqlite3`，采用中文二元词片和英文词检索，优先使用 SQLite FTS5，缺失时采用本地词项回退。索引损坏会保留故障文件并重建，无法落盘时可使用内存索引；它不替代正文或 P0 归档。

检索使用本章问题、采用计划的正文内容、章纲与明确别名，不使用计划文件里的哈希和路径作为故事关键词。原文结果包含来源、原始文件 SHA256、规范化文本的 start/end 偏移；事实事件、人物认知、传言、作者参考与原文片段保持不同类型。预算省略、查询裁切和失效命中都有诊断字段。检索读集覆盖实际提供的段落、状态、认知、修正链、身份目录和时间输入；后验开始时冻结读集，之后不从可变的共享上下文猜测。

## 身份

可选作者目录 `meta/entity_registry.json`：

```json
{"entities":[{"id":"character-lin","name":"林照","aliases":["阿七"]}]}
```

编号在本书内稳定，称呼重叠时报告歧义。后验观察沿用已确认编号；未知称呼不能直接借用已有编号。仲裁器可通过有正文依据的 identity_rulings 确认别名，身份元数据独立保存，即使本章没有人物状态变化也不会丢失。已分别建档的身份存在冲突时保留歧义，不根据称呼相似自动合并。作者身份映射不等于角色已识破身份。

## 认知与时间

可选 memory_events 分类为 fact、knowledge、belief、rumor。后三者需要持有者和获知/信念来源，均需本章真实原文证据。无歧义姓名可归一化为编号。计划不进入事实事件。supersedes 显式表达事实更新或同主体认知纠正；被替代的命中会标记并带回修正链，不能孤立当作当前事实。

未记录获知不等于确定不知，常识和推断依本书规则核验。叙述者权限、可靠性、揭示时机仍遵循每书契约；不统一限知或强制客观叙述。

非线性叙事可在本章 planned_world_state.json 与事件中提供可选整数 world_time_key，表示本书明确的时间先后。没有值时仅按叙事章节排除未来资料，不虚构历法。指定回溯时间时，之后获得的知识不进入本场景认知，时间未知的记录标为未核实；无法证明适用于本场景的最新人物/世界状态不再被标作当前状态。

世界演进后处理保留已明确的时间锚点，生成值冲突时拒绝覆盖。计划的时间依赖使用 `@memory/scene-time/章号` 的选定 JSON 字段摘要，区别于原文文件哈希；普通世界元数据更新不会因此使计划失效。来源校验与旧书兼容逻辑都识别该语义依赖。

## 旧章修改

`archive/impact_report.json` 随归档/刷新事务更新，续写预检也即时提供 impact 诊断。它列出变更来源、依赖失效的章节、受影响计划、实际检索过的证据和复核建议。传播考虑上游语义失效，即使上游快照文件还未重建、字节未变，也不放行其依赖。

实际读集用于优先复核排序，不能证明其他章节没有隐含因果影响。未知依赖继续使用 P0 保守检查。重新审核并归档后，失效队列按当前来源重算。功能不自动重写后文，不删改原稿，也不要求所有伏笔回收或采用固定节奏。

在作品副本目录执行 `story_support recall --chapter 0201 --query "线索或别名"` 查看检索证据，或 `story_support impact` 查看影响图。命令沿用插件脚本库运行方式。

当前检索采用词项与明确身份关系，不保证无词面联系的隐喻或同义转述全部召回。全文来源核验仍有全历史扫描成本；索引更新复用并不代表百万字生产性能已经验证。
