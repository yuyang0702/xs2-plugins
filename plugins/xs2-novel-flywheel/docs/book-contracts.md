# 按作品配置世界规则与文风

通用检查核对本书规则，题材不自动决定写法。默认保留已有文风；全知、变换视角、不可靠叙述、抒情回环、象征和必要说明都可以使用。

## 在作品设置中填写

- **叙事视角**：`first_person`或`third_person`，表示人称基线。
- **叙述权限**：`preserve`保留现有、`limited`限知、`omniscient`全知、`variable`允许有意转换、`unreliable`不可靠叙述。
- **本书文风要求**：自由描述语言、节奏、心理、意象、说明和重复的用途；不必选择固定风格预设。

沿用本书的`meta/style_profile.md`、`meta/world_foundation.md`及已采用的叙述偏好。人物行动所需知识仍须有依据；叙述者的权限与人物所知分开检查。

## 声明有意表达与保护用语

可在本书工作区新增`meta/narrative_contract.json`。这是作者配置，不放进插件通用模板。文件中明确声明的字段优先于作品设置中的同名值；需要改回页面配置时删除对应字段。

```json
{
  "schema": 1,
  "narrator_scope": "variable",
  "style_intent": "第三人称与明确标识的第一人称回忆交错，容许抒情回环",
  "intentional_devices": ["同一句话在不同处境中改变含义"],
  "protected_phrases": ["潮水会回来。"],
  "allow_repeated_passages": true
}
```

`protected_phrases`保护表达修订前已经存在的用语，防止被当作普通重复删除；它不代替正文生成检查。`allow_repeated_passages`声明有意复沓，审稿仍须判断其具体功能。缺失配置不等于禁止这些写法。

## 查看与继续一次生成

写作、情境审稿和修订读取同一份任务冻结契约；独立盲读只接收公开文风和叙述权限，不接收私下剧情答案。任务开始后改变世界、文风或叙述权限，需要新建任务，旧核验不能批准新配置。

单写手与多写手都先规划适用的事实和事件，再经过事实核验、局部表达修订与独立复查。没有交易的故事不生成钱款账；需要精确跟踪的水、电源等库存分开核算，不强行互相换算。

表达修订按当前段落和精确原句提交补丁，程序保留未改文字，并先复核篇幅。审稿可选择当前稿的段落、分句或金额编号，引用由程序回取。无效引用退回核验者，真实问题退回相应写手；事实通过不代表表达或最终阅读评估已通过。

检测报告可用于定位待审段落。内部检查不等同于第三方AI检测，也不承诺某一检测分数；判断须结合完整正文、作者文风及世界规则。

## 独立润色与表达验收

独立润色的内容修订也使用局部补丁。自审、写手和独立验收读取同一次冻结原文、本书规则、作者意见、人物声线适配和已采用参考；未修改的文字原样保留。候选先检查篇幅，再分别核对事实、表达、每项改动的净效果和原问题是否解决。写手返修后必须重新审查新候选，不能复用旧通过记录。没有必要修改时可以提交空补丁，仍须审阅当前全文。

读者审稿和局部修订验收按六个维度给出当前原文与本书风格依据：语义增量、后台条件是否直写、意象作用、对白作用、结尾作用、声线一致性。允许的风格仍需说明该段作用；华丽、心理、技术说明、复沓、喜剧和不可靠叙述都不因形式本身被判错。中高优先级表达问题单独阻止通过，事实无误或总分较高不能代替修复。

两个小说顾问入口都使用当前有效的世界与文风规则。网页顾问包含待保存的作品设置；独立顾问冻结作者的篇幅与短篇/连载范围。分析期间规则改变时旧建议不发布；建议不会自动改成作者已采用的规则。
